# Checkmate Crew Chess Website

Static chess practice website for GitHub Pages.

## Publish
1. Upload all files in this folder to the root of your GitHub Pages repository.
2. In repository Settings → Pages, set the custom domain to `checkmatecrew.online`.
3. Enable Enforce HTTPS when GitHub Pages makes it available.

The site is a browser-only prototype; it does not include online multiplayer or server-side accounts.
